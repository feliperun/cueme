# Golden — `index.md`

Two shapes. The bundle root carries `okf_version` and nothing else may; a nested
`index.md` has no frontmatter at all. Both list **direct children only**, sorted by
title, with the child's `description` after an en dash. A child with no
`description` is listed without one.

Regenerated by `CorpusStore.writeIndexes` once per batch, never per save, and the
write is skipped when the rendered bytes are unchanged.

## Bundle root — `<root>/index.md`

```markdown
---
okf_version: "0.2"
---

# Notas

* [Acme](acme.md) - Contexto e histórico da conta Acme.
* [Inbox](inbox.md)
* [Pessoas](pessoas.md) - Quem aparece nas reuniões.
```

## Nested — `<root>/acme/index.md`

```markdown
# Acme

* [Atas](atas.md) - Registro das reuniões da conta.
* [Proposta comercial](proposta-comercial.md)
```

The heading is the parent note's title. At the root it is the literal `Notas`,
because the root has no parent note.
