**Veredito: aprovado na rodada 1.** Commit `4cf17dd`.

## Rodada 0 — uma mudança pedida

O agente adicionou `nonisolated(unsafe) static var timeZoneOverride: TimeZone?`
para deixar `untitledSlug` determinístico no teste, alegando que a superfície
declarada não recebia `TimeZone`.

Devolvido: estado global mutável dentro de um tipo que a própria tarefa define
como cálculo puro contraria a `constitution.md` §4, que exige testes isolados sem
estado compartilhado — passa a depender de disciplina de `tearDown` para não
vazar entre casos. Um parâmetro com valor padrão resolve o mesmo sem nenhum desses
custos:

```swift
static func untitledSlug(startedAt: Date, timeZone: TimeZone = .current) -> String
```

Nenhum call site de produção muda, o teste passa a timezone direto, e o
`tearDown` some. O argumento de que "a superfície não declarava `TimeZone`" não
se sustentava: ele já tinha adicionado um `static var` que também não estava lá —
entre os dois desvios, o parâmetro é o menos invasivo. O paralelo com
`SessionStore.rootOverride` também não valia: aquele existe porque `rootURL` é
lido indiretamente por dezenas de call sites que não podem receber argumento.

## Diff

`isReserved` tem duas convenções de chamada — nome nu para entrada tipo-diretório
(`raw`), nome com extensão para tipo-arquivo (`index.md`, `log.md`, `AGENTS.md`) —
e a assimetria está documentada no doc comment e coberta por teste. Correto: `raw`
nunca é reservado na raiz, porque a raiz não é a pasta de uma nota.

`uniqueSlug` usa um **contador único** compartilhado entre "reservado" e "já
tomado", então `uniqueSlug("index", taken: ["index-2"])` devolve `"index-3"`.
É a leitura certa da regra, e está testada explicitamente. A decisão de tratar
`raw` como reservado mesmo na raiz (mais conservador que o necessário) está
documentada no doc comment e não perde dado.

Zero I/O, como a tarefa exigia. Fallback de slug vazio é `nota`, conforme a regra
da tarefa e não o `project` herdado do `ProjectWorkspaceStore`.
